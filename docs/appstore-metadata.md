## 概要（4000文字以内）

```
「あと2てん！」が、子どものやる気になる。

ごほうびプラスは、おてつだいや宿題ができたらポイントがたまり、目標の点数に届いたらごほうびがもらえる、子ども向けのごほうびポイント管理アプリです。

冷蔵庫に貼った紙のシール表を、そのままiPhoneに。ちがうのは、子ども自身が開いて、あと何点でごほうびかがひと目で分かること。


■ 「あと何点」を、いちばん大きく

「現在3ポイント」ではなく「あと 2てん！」。
子どもが見て分かる言葉と大きさで、ごほうびまでの残りを表示します。星やゲージで進みぐあいが見えるので、まだ数字が読めないお子さんでも、あとどれくらいかが伝わります。


■ 押すのは子ども、決めるのは親

子どもは、できた行動の「できた！」を押すだけ。
ポイントはすぐには増えず「かくにんまち」になり、親モードで承認してはじめて加算されます。押しただけで点が入らないので、こっそり連打も、水増しもできません。

（承認をオフにして、押した時点で加点する設定にもできます）


■ 親モードは、しっかりロック

親アイコンを1秒長押しして、Face IDまたは端末のパスコードで解錠します。生体認証が使えない場合は、アプリ内の4桁パスコードで開けます。子どもが勝手に設定やポイントを変えることはありません。


■ 家庭のルールに合わせて設定

・やることの追加・編集（名前、絵文字、ポイント、並び順）
・1日に何回までポイントになるかの上限（「なんかいでも」にもできます）
・曜日ごとの出し分け（月〜金だけの「宿題」、土日だけの「おふろそうじ」など）
・ごほうびと目標ポイントの設定
・ポイントの手動修正（履歴に残ります）
・子どもの登録（きょうだい何人でもOK。名前とアイコンを設定して切り替え）


■ ごほうびタイマー

ごほうびが「Switch 30ぷん」のように時間を含むときは、受け取ったタイミングからアプリが残り時間を計ります。リングと数字で残りが見えるので「もうおしまい」でもめにくく、アプリを閉じても続きから再開します。


■ がんばりが続く仕組み

・目標に届いたときの達成演出
・連続で達成した日数の表示
・「できた！」のたびに鳴る効果音と、手ごたえのある触覚フィードバック


■ 1日の区切りは朝4時

ポイントとかくにんまちは、毎日リセットされます。切り替わるのは深夜0時ではなく朝4時なので、夜おそくに押した「できた！」を、日付が変わったあとでも承認できます。

やることや設定、ごほうび、目標ポイントは、翌日以降もそのまま引き継がれます。


■ 通知（使わなくてもOK）

・承認のうながし：申請から5分たっても承認されていないときだけ
・毎日のリマインド：指定した時刻に1回だけ

どちらもオフにできます。


■ プライバシー

・サーバーへの通信機能がありません
・アカウント登録もログインも不要です
・広告も、アプリ内課金も、トラッキングもありません
・入力したデータはすべて端末の中だけに保存されます（親モードのパスコードはハッシュ化して保存）

お子さんの名前や記録が、開発者を含む第三者に渡ることはありません。


■ こんなご家庭に

・「5点たまったらごほうび」を紙で運用していた
・お手伝いや宿題の声かけに疲れてきた
・シール表を作るのも、貼るのも、続かなかった
・きょうだいそれぞれのがんばりを分けて記録したい


対応環境: iOS 26以降 / iPhone
```

```
This is a reward-points app for families. A child taps "done" on chores or homework,

1. On the child's home screen, tap the orange "できた！" (done) button on a task card.
```

## メモ（日本語・控え）

```
ご確認ありがとうございます。

家庭向けのごほうびポイント管理アプリです。子どもがお手伝いや宿題の「できた！」を押し、
親が承認するとポイントがたまり、目標に届くとごほうびがもらえます。

■ 親モードの開き方（最初にご確認ください）

機能の大半は親モードにあります。子どもが勝手にルールを変えられないよう、意図的に
入口を隠しています。

1. 子ども画面の右上にある人物アイコンを「1秒長押し」します。短いタップでは反応しません。
2. Face ID / Touch ID / 端末のパスコードで認証します。
3. 生体認証も端末パスコードも設定されていない端末では、アプリ内の4桁パスコード画面に
   切り替わります。初回は任意の4桁（例：1234）を登録する流れになります。

サーバーもアカウントも持たないため、デモアカウントはありません。データはすべて端末内
にのみ保存されます。

■ 初回起動

セットアップ（ごほうび → 行動 → 完了）のあと、子ども画面が表示されます。

■ 主な操作

1. 子ども画面で行動カードの「できた！」を押す → 「かくにんまち」になり、ポイントはまだ
   増えません。

- 「1日」は深夜0時ではなく朝4時に切り替わります。夜遅くに押した「できた！」を、
```

## 添付する操作動画

40〜60秒の画面収録を1本。ねらいは「審査員が親モードに入れずに詰まる」のを防ぐこと。

1. 子ども画面 → 右上のアイコンを1秒長押し → 認証 → 親モードが開く（ここが最重要）
2. 「できた！」→「かくにんまち」→ 親モードで承認 → ポイントが増える
3. 目標達成 →「ごほうびをもらった」→ タイマーが始まる

実機の画面収録（.mp4 / .mov）でよい。添付ファイルにはサイズ上限があるため、収まらない
場合は限定公開の動画URLをメモ本文に書く方法もある。
