ごほうびプラス（あとなんてん？）

プライバシーポリシー

最終更新日: 2026年8月29日

本アプリは、入力されたデータをすべてお使いの端末の中だけに保存します。サーバーへ送信する機能を持たず、開発者がデータを受け取ったり閲覧したりすることはありません。アカウント登録もログインも不要です。

1. 基本方針

iOSアプリ「ごほうびプラス」（以下「本アプリ」）は、子どものごほうびポイントを家庭内で管理するためのアプリです。本アプリはネットワーク通信を行わず、すべての処理と保存を端末内で完結させます。

2. 端末内に保存される情報

本アプリは、次の情報を端末内（SwiftData / UserDefaults）に保存します。

種類内容
子どもの情報名前（ニックネームでもかまいません）、アイコンの絵文字
行動（やること）名前、絵文字、ポイント、1日の上限、表示する曜日、並び順、表示 / 非表示
ごほうび名前、絵文字、目標ポイント、ごほうびタイマーの残り時間
ポイントの記録現在のポイント、承認待ちの申請、ポイント履歴、達成記録、ごほうびの受け取り記録とその日時
アプリの設定承認の要否、通知の有無と時刻、見た目（ライト / ダーク）、効果音の有無
親モードのパスコード4桁のパスコードは、そのままではなく SHA-256 でハッシュ化した値のみを保存します

これらは端末外へ送信されません。

3. 取得しない情報

本アプリは次の情報を取得しません。

  • 氏名・住所・電話番号・メールアドレスなど、個人を特定する情報の入力を求めません
  • 位置情報、連絡先、写真、カメラ、マイク、ヘルスケアデータ
  • 広告識別子（IDFA）その他のトラッキング用の識別子
  • 利用状況の分析データ（アクセス解析）、独自のクラッシュログ

広告の表示、アプリ内課金、第三者製の SDK・解析ツールの組み込みはいずれもありません。

4. 外部への送信

本アプリはネットワーク通信を行いません。したがって、入力された情報が外部のサーバーや第三者へ送信されることはありません。

5. Face ID・端末のパスコードについて

親モードを開くときに、iOS の認証（Face ID / Touch ID / 端末のパスコード）を利用します。本アプリが受け取るのは認証に成功したかどうかの結果だけです。顔や指紋のデータは iOS が管理しており、本アプリから参照することはできません。

生体認証も端末のパスコードも利用できない場合に備えて、本アプリ内の4桁パスコードを登録できます。これは前述のとおりハッシュ化して端末内に保存します。

6. 通知について

通知はすべて端末内で作成・表示されるローカル通知です。承認待ちのお知らせや毎日のリマインドに、子どもの名前や行動の名前を含めることがありますが、これらも端末の外には出ません。通知の許可は任意で、iOS の「設定」からいつでも変更できます。

7. バックアップについて

端末で iCloud バックアップやパソコンへのバックアップを有効にしている場合、iOS の仕組みによって本アプリのデータもバックアップに含まれることがあります。バックアップの保存や管理は Apple のサービスによるもので、その取り扱いは Apple のプライバシーポリシー に従います。

8. お子さまの情報について

本アプリは子どもが使うことを想定していますが、前述のとおり情報を外部に送信しないため、開発者が子どもの情報を収集・保有することはありません。名前はニックネームでの登録もできます。行動やごほうびの内容の設定、データの管理は保護者の方が行ってください。

9. データの削除

  • 特定の子どもの記録を消す: 親モード →「子どもの管理」→ 対象の子どもを削除
  • すべての記録を消す: 親モード →「アプリの設定」→「すべてのデータを削除」
  • 端末から本アプリを削除すると、端末内のデータもあわせて削除されます

開発者側でデータを保管していないため、削除のご依頼をいただく必要はありません。

10. 第三者への提供

本アプリは利用者の情報を保有しないため、第三者へ提供・販売することはありません。

11. 本ポリシーの変更

内容を変更する場合は、このページを更新します。重要な変更があるときは、アプリのアップデート情報でもお知らせします。
