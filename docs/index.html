ごほうびプラス

あと何点でごほうびかが、ひと目で分かる

⭐️ あと 2てん！ ⭐️

⭐️ ⭐️ ⭐️ ☆ ☆

3 / 5 てん　🎮 Switch 30ぷん

「宿題」「読書」「お手伝い」などができたらポイントがたまり、目標ポイントに到達するとごほうびを獲得できる、子ども向けのごほうびポイント管理アプリです。紙で運用していた「5点たまったらごほうび」の仕組みを、子ども自身が使える形にしました。

できること

  • 「できた！」を押すと承認待ちになり、親モードで承認するとポイントが加算されます
  • 星やゲージで「あと○てん」を大きく表示します
  • 行動、ごほうび、目標ポイント、1日の上限、表示する曜日を親モードで設定できます
  • ごほうびタイマー、連続達成日数、履歴に対応しています
  • きょうだいで使えるよう、子どもを複数登録できます

プライバシー

データはすべて端末内に保存され、外部には送信されません。詳しくは プライバシーポリシー をご覧ください。
